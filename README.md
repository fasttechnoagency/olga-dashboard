# لوحة تحكم أولغا — نسخة مقسّمة

- `index.html` — هيكل الصفحة فقط.
- `style.css` — كل التنسيقات.
- `script.js` — كل الأكواد البرمجية (تسجيل الدخول، المنتجات، الطلبات، العملاء، الكوبونات، العروض، الإعدادات...).
- `assets/data/config.js` — روابط ومفاتيح السيرفر في مكان واحد.

ارفع المجلد كاملاً كما هو. ترتيب تحميل الملفات مهم: مكتبة Supabase ثم config.js ثم script.js.
